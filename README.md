# Mini Scan

Небольшая программа для Windows: сканирование документов в PDF и JPG без OCR и распознавания текста.

Готовая сборка: [Releases](https://github.com/allaenel-lang/miniscan/releases/latest).

## Возможности

- Выбор TWAIN-сканера и настройка цвета, разрешения, формата бумаги, автоподачи и дуплекса.
- Компактная верхняя панель: выбранный модуль сканирования, его состояние, количество сканов и пауза между ними в одном ряду.
- При запуске окно прикрепляется к верхнему краю экрана.
- Значок со стрелками рядом с модулем меняет сканер, значок шестерёнки открывает настройки сканирования.
- Многократное сканирование: каждая страница добавляется в список слева.
- Увеличенные миниатюры: в обычном окне одновременно видно не менее четырёх страниц, изображение полностью вписано в блок без серых полей.
- На каждой миниатюре есть маленькие кнопки поворота влево и вправо.
- Предпросмотр страницы с масштабированием:
  - по умолчанию страница заполняет ширину области;
  - кнопки «−» и «+» меняют масштаб;
  - нажатие на процент сбрасывает масштаб к ширине области;
  - колесо мыши и перетаскивание прокручивают страницу; при увеличении доступна прокрутка и по горизонтали.
- Выбор страниц: клик, Ctrl+клик, Shift+клик, правый клик.
- Сохранение в PDF:
  - одна многостраничная PDF;
  - или отдельная PDF для каждой страницы (флажок «Каждая страница отдельно»).
- В окне сохранения PDF есть флажок «Всегда сохранять в эту папку».
- Если папка сохранения находится на рабочем столе, вместо полного пути показывается «Рабочий стол» или «Рабочий стол\...».
- Сохранение в JPG: выбранные страницы или текущая страница; в окне сохранения есть флажок «Всегда сохранять в эту папку».
- Поворот страниц влево/вправо: кнопками на миниатюре или из меню по правому клику.
- Контекстное меню по правому клику: PDF, JPG, поворот, удаление.
- Все изображения сохраняются локально. Сеть не используется.

## Как пользоваться

1. Запустите `MiniScan.exe`.
2. Нажмите маленький значок со стрелками рядом с надписью модуля и выберите TWAIN-источник.
3. При необходимости нажмите шестерёнку и задайте цвет, DPI, формат бумаги, автоподачу и дуплекс.
4. Задайте в поле «Сканов» количество сканирований за один запуск и при необходимости паузу между ними. Нажмите «Сканировать»: первый скан начнётся сразу, следующие — после паузы.
5. Выберите нужные страницы в списке слева. Для поворота используйте маленькие кнопки на миниатюре или правый клик.
6. Нажмите «Сохранить» и выберите PDF или JPG.

Для PDF без флажка «Каждая страница отдельно» все выбранные страницы попадут в один файл. С флажком будут созданы файлы `Скан_001.pdf`, `Скан_002.pdf` и т. д.

Флажок «Всегда сохранять в эту папку» запоминает папку для следующих сохранений. Окно сохранения при этом по-прежнему открывается: так можно изменить имя файла или папку и не перезаписать документ случайно.

## Несколько сканов подряд

- Поле «Сканов» задаёт, сколько сканирований выполнить за один запуск: от 1 до 999. По умолчанию — 1.
- Поле «Пауза, с» задаёт паузу после очередного скана перед следующим. По умолчанию — 10 секунд. Перед первым сканом паузы нет.
- Первый скан начинается сразу после нажатия «Сканировать», следующие запускаются автоматически.
- Пока в очереди остались сканы, кнопка «Сканировать» заменяется на «Стоп (N)», где N — сколько сканов ещё осталось. Нажатие останавливает очередь; уже добавленные страницы остаются.
- После заданного количества сканов серия завершается.
- Ошибка или отмена сканирования останавливает серию; можно сразу начать новую.
- Во время паузы в строке состояния видно, сколько сканов осталось и сколько секунд до следующего.
- После закрытия окна TWAIN-сканера фокус возвращается в окно программы.

## Сохранение на рабочий стол

Если выбрать рабочий стол, в поле пути отображается:

- `Рабочий стол` — когда сохраняется в саму папку рабочего стола;
- `Рабочий стол\Скан.pdf` — когда указан файл на рабочем столе;
- `Рабочий стол\Подпапка` — когда выбрана папка внутри рабочего стола.

При сохранении эти понятные пути автоматически заменяются на настоящий путь рабочего стола.

## Масштаб предпросмотра

- `100%` — страница заполняет ширину области предпросмотра.
- «−» / «+» — шаг 25%, от 25% до 300%.
- Нажатие на процент — вернуть заполнение по ширине.
- Если страница выше области, справа появляется полоса прокрутки; работают колесо мыши и перетаскивание.
- При увеличении страницу можно двигать мышью в любую сторону, в том числе по горизонтали; внизу появляется горизонтальная полоса прокрутки, которую можно перетаскивать. Shift + колесо мыши также прокручивает по горизонтали.
- Ctrl + «+», Ctrl + «−», Ctrl + 0 — те же действия с клавиатуры.

## Требования

- Windows 10 или Windows 11 (x64).
- .NET Framework 4.8 (входит в состав Windows 10/11).
- 32-битный TWAIN-драйвер сканера. Программа собрана как x86, потому что многие TWAIN-источники доступны только в 32-битном виде.

## Сборка

В папке проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт использует компилятор `csc.exe` из .NET Framework 4.x и создаёт:

- `dist\MiniScan\MiniScan.exe`
- `dist\MiniScan\NTwain.dll`
- `dist\MiniScan\MiniScan.exe.config`
- `dist\MiniScan\README.md`
- `dist\MiniScan-win32.zip`

Для сборки нужны только .NET Framework и файлы проекта; Visual Studio и .NET SDK не требуются.

## Ограничения

- Нет OCR: текст в PDF остаётся частью изображения.
- PDF создаётся собственным минимальным writer'ом, JPEG встраивается в PDF как `DCTDecode`.
- Приложение не отправляет документы в интернет и не требует учётной записи.

## Если сканер не найден

- Убедитесь, что установлен 32-битный TWAIN-драйвер (не только WIA).
- Закройте другие программы, которые уже захватили сканер.
- Нажмите значок смены сканера рядом с модулем и обновите список.
- Для Brother DCP-T500W используется источник `TW-Brother DCP-T500W`.
